# 미리캔버스 디자인허브 기여자 가이드 (정리본)

> 출처: 디자인허브 가이드 페이지 스크린샷 (2026-07-06 캡처) 정리.
> 공식 가이드가 바뀔 수 있으니, 애매하면 원문을 다시 확인할 것.
> 모든 가이드 공통 문구: **"가이드 미숙지로 인해 발생하는 문제는 기여자 본인에게 책임이 있습니다."**
> 디자인허브는 **Adobe 프로그램** 사용을 권장 (다른 프로그램은 기술 지원 어려움).

---

## 1. 파일 규격 (크롭 *완료 후* 기준)

| 카테고리 | 확장자 | 최소 dpi | 최소 px | 최대 px | 최대 용량 |
|---|---|---|---|---|---|
| 사진 | JPG | 120 | 2500 | 9800 | 50MB |
| 배경 제거 사진 | PNG | 120 | 2500 | 9800 | 50MB |
| PNG 요소 | PNG | 120 | 700 | 9800 | 50MB |
| SVG 요소 | SVG | 72 | - | 6000 | 150MB |
| GIF 요소 | GIF | 72 | 700 | 1920 | 25MB |
| 배경 | JPG | 120 | 2500 | 9800 | 50MB |
| 동영상 | MP4 | - | - | - | 120MB (30초 이내) |

- 사진: 가로/세로 **변 모두** 2500~9800px 충족해야 함.
- 사진에 인물·제3자 재산 포함 시 초상권/재산권 계약서 구비 필요 (요청 시 제출).
- 제3자 로고·상표 포함 콘텐츠는 서비스 불가.

## 2. 콘텐츠 타입 선택

| 타입 | 해당 콘텐츠 |
|---|---|
| 사진 (JPG) | 촬영된 실사 사진. 하늘·풍경 같은 실사도 '배경'이 아니라 **'사진'**으로 제출 |
| 배경 (JPG) | 사각형 형태, 사용자 문서의 배경용. **피사체가 없는 그래픽 일러스트** 또는 **특정 피사체가 돋보이지 않는 조화로운 패턴**만 허용 |
| 배경 제거 사진 (PNG) | 실사 사진 / 실사와 매우 흡사하게 생성된 사진에서 배경을 완벽히 제거한 피사체 |
| PNG 요소 | 배경을 완벽히 제거한 그림·아트·일러스트. **3D, 그라데이션 포함**된 것도 여기 |
| SVG 요소 | 배경 제거 일러스트 중 **색상 5개 이하**, **복잡하지 않은** 형태, **단색만** 사용 |
| GIF 요소 | 배경 제거 + **움직이는** 그림·아트·일러스트 |
| 동영상 | 특정 주제로 촬영된 영상 |

배경 미허용: ① 실사 사진(→사진으로) ② 피사체(인물·동물·사물)가 있는 사각형 일러스트(→단일 객체로 분리해 제출, 분리 불가하면 지원 불가).

## 3. 요소 공통 필수 작업

### 3-1. 요소 사이즈 크롭
- 피사체 가장자리에 **여백 없이 딱 맞게** 크롭. 안 되면 사용성 저하로 서비스 어려움.
- 디자인 프로그램 내 기능으로 크롭. 크롭 후 크기가 파일 규격에 맞아야 함.

### 3-2. 단일 객체로 분리
- 배경 제거 사진 / PNG / SVG / GIF 요소는 **파일 하나에 피사체 하나**.
- 두 개 이상이면 심사 거부될 수 있음. (예: 의사 3명 그림 → 3개 파일로 분리)

## 4. SVG 요소 추가 규칙

### 4-1. 색상 정리 (최대 5색 권장)
- 비슷한 계열 색은 하나로 통일. 색이 많으면 사용자가 색 변경하기 불편.

### 4-2. 명암·하이라이트 & 색상 잠금
1. 하이라이트 → 흰색 `#FFFFFF`
2. 명암(그림자) → 검정 `#000000`
3. 불투명도(Opacity)로 조절
4. 업로드 후 메타데이터 입력 시 흰색·검정을 **'색상 잠금'** 처리
→ 사용자가 바꿔야 할 색 수가 줄어 사용성↑

### 4-3. 크랙 방지 (색 경계에 생기는 실선)
1. 완성된 요소 복제
2. 복제본을 Pathfinder → **Unite**로 하나의 오브젝트로 합침
3. 합친 복제본을 원본 **뒤에** 깔기

## 5. 확장형 SVG 요소
- 별도 타입 아님. SVG 요소 업로드 후 **콘텐츠 업로드 > 제출 예정 > 우측 메타데이터 패널 > 크기조정 타입 > '확장형'**.
- 특정 부분만 형태가 깨지지 않게 늘어나는 요소. 연필, 말풍선, 메모지, 상자, 깃발 등에 추천.
- 확장 방향: 가로 / 세로 / 가로+세로.
- 확장 영역 설정: 파란색 = **고정 영역**(늘어나지 않음). 위치가 부적절하면 "가이드선을 조정하여 고정 영역을 변경해 주세요" 메시지. '미리보기'로 확인. 확장 시 형태가 일그러지면 심사 거부.
- 확장 가능 영역이 없으면 '기본형'으로 제출.

**확장형 제출 불가 사례**
1. 확장 구간이 **곡선** (직선 구간만 지정 가능)
2. 오브젝트에 **회전/기울기** 값 → 오브젝트 선택 > 우클릭 > Transform > **Reset Bounding Box** (그래도 간헐적 업로드 불가 → 처음부터 회전 없이 작업 권장)
3. **텍스트·획(stroke)** 남아 있음 → 모든 디자인은 면으로만.
   - 텍스트: Type > **Create Outlines**
   - 선: Object > Path > **Outline Stroke**
   - 어려우면 SVG 불가 → PNG 요소로
4. **그라데이션** 포함 → SVG 불가, PNG 요소로 제출

## 6. 조합 요소
- 일정 기준 이상 업로드 활동을 달성하면 기능 활성화.
- 내가 등록한 요소 + 미리캔버스 제공 콘텐츠를 에디터에서 조합 → **디자인 문서 URL**로 등록.
- 장점: 한 번 사용 시 포함된 **내 요소 전부 수익** 발생 (타인 요소는 정산 안 됨). 사용자가 위치·크기·텍스트 변경 가능.
- **반드시 미리캔버스 에디터**로 제작 (디자인 프로그램 X).
- 사용 가능한 개별 요소: 텍스트, PNG 요소, SVG 요소, 기본 도형, 선, 애니.

**콘텐츠 타입 2가지**
1. **디자인 조합**: 일러스트·도형·아이콘·텍스트를 조합한 그래픽 중심. 단순 나열 불가, 주제·의미가 명확한 완성형이어야 함.
2. **텍스트 스타일**: 텍스트 기반 (제목 스타일, 로고 타이틀, 효과음, 감정 표현). 텍스트 박스 1개 이상 필수. 텍스트는 정산 대상 아님.

**업로드 주의사항**
1. 반드시 **한 페이지**에서 제작 (2페이지 이상 문서 불가)
2. **최종 그룹화** 필수
3. **배경 미적용** (설정해도 반영 안 됨)
4. 요소(핸들 영역 포함)가 **대지 밖으로 벗어나면 안 됨** — 최종 반영은 대지 내부 기준
5. 요소가 **대지에 꽉 차게** 제작. 추천 대지: 카드뉴스 `1080×1080` 또는 인스타그램 프로필 사진 `720×720` (정사각형). 대지가 너무 크면 화질 저하로 거절.
6. **서로 다른 요소 2개 이상 + 총 요소 3개 이상** (텍스트도 1개로 침). 같은 요소만 반복 X.
7. 동일 구성 요소로 개수만 바꿔 재제출 불가
8. 텍스트는 **편집 가능한 텍스트 박스**로 (캘리그래피 등 고정 이미지 텍스트 → 반려)

## 7. 컬렉션
비슷한 스타일·테마·컨셉·주제로 만든 요소를 하나로 묶는 기능. 빠른 탐색 + 템플릿 연계에 유리.

**필수 조건**
1. 최소 **6개** 요소
2. **동일 콘텐츠 타입**만 (가능 타입: PNG 요소, SVG 요소, GIF 애니)
3. 요소 하나는 **하나의 컬렉션에만**
4. 동일 스타일·테마·컨셉·주제
5. 모든 구성 요소가 **"공개"** 상태
- 제작 개수 제한 있음 (관리자 검토로 조정). 별도 심사 없음 → 부적절 시 수정/비공개/비활성.

**이름**
- '~컬렉션', '~모음', '~묶음' 포함 금지.
- 좋은 예: 안녕, 난 귀여운 빨간 곰이야 / 바다를 즐기기 위한 준비 / 다양한 포즈와 상황의 귀여운 동물 친구들 / 즐거운 쇼핑타임 / 선으로 그린 귀여운 동물들 / 맛있는 일본 길거리 간식 / 전국의 빵순이 빵돌이 모여라!
- 나쁜 예: 발렌타인데이 일러스트 컬렉션 / 벚꽃 그림 모음 / 감정표현 모음 / 길거리 간식 묶음
- 올바른 예시: 미소 가득! 활기찬 선생님 / 기쁜 표정의 이모지 / 물놀이를 즐기는 사람들 / 즐거운 소비생활

**메타데이터**
- 키워드: 최대 25개, 중복 불가. 구성 요소의 교집합 + 컬렉션 관련 키워드. 무관한 키워드 → 비공개 위험.
- '선택된 콘텐츠의 모든 키워드': 클릭해서 추가 가능, 공통 키워드는 파란색.
- 요소 ID: 앞 4개가 **썸네일**. 추가한 순서 = 노출 순서.
- 'ID 입력하여 추가': ID 입력(여러 개는 쉼표) → ENTER → '추가'.

**만드는 법** (내 콘텐츠 관리 > 요소)
- 방법1: '컬렉션 만들기' 아이콘 → 요소 클릭 후 '+ 컬렉션 요소 추가' → 다음 → 메타데이터 → 등록
- 방법2: 요소 여러 개 선택 → 우측 패널 '컬렉션 만들기' (안 보이면 ⓘ) → 다음 → 메타데이터 → 등록
- 등록된 컬렉션은 [컬렉션] 페이지에서 확인.

## 8. 템플릿 제작 시 주의사항
1. **QR코드**: URL에 `https://www.miricanvas.com/` 입력
2. **바코드**: 숫자 '0'으로 입력 (EAN-13: 12자리, EAN-8: 7자리)
3. 대표 캐릭터 **'아고'**(초록 악어)는 사용 가능, 단 **임의 변형 금지**
4. **인물 사진** 사용 시 `*페이지 내 인물 사진은 샘플이미지 입니다.` 문구 필수 (없으면 거부)

## 9. 저작권
- 제출 콘텐츠 문제 시 **기여자 본인 책임**으로 원저작자와 협의·보상.
- 본인의 유일한 창작물/소유물이어야 함.

**제출 불가**
1. 제3자 권리(저작권, 초상권, 재산권 등) 침해
2. 음란물, 명예훼손, 불법·비도덕적 내용
3. 불법·폭력 행동 묘사
4. 동물 학대·폭력
5. 사기성 광고, 불공정 경쟁
6. 상표, 디자인 마크, 사업자명, 로고 (일부 포함도)
- ⚠️ 미리캔버스 및 타 사이트 **템플릿 레이아웃/디자인과 유사**해도 저작권 침해로 제재 가능.

## 10. 콘텐츠샵 (상품 판매)
- 내가 디자인한 상품을 파는 온라인 스토어 + 내 요소·컬렉션·템플릿 전시 공간.
- 상품 제작·재고·배송·CS를 미리캔버스가 담당. 운영비·수수료 0원, 상품 500+개 제작 가능.
- 미리캔버스 + 비즈하우스 2,000만+ 고객에게 노출. 개인·기업 누구나 오픈 가능.
- 실적 (2025.09.10 기준): 테마전 참여자 3명 중 1명 판매 성공, 누적 5천만원 매출 샵 존재, 상품 하나로 누적 52만원 사례.

### 나의 샵 설정 (디자인허브 [나의 샵 > 샵 관리])
권한 오픈 후 별도 심사 없이 등록. 부적절하면 비공개/비활성.

| 항목 | 규칙 |
|---|---|
| 샵 프로필 | 2~4000px, 4MB 이하, JPG/PNG/GIF |
| 샵 이름 | 최대 32자, 중복 허용 |
| 샵 소개글 | 메인에 노출되는 설명 |
| 샵 주소 | 3~20자, 영문 소문자·특수문자(`_` `-`), 중복 불가, **30일에 한 번** 변경 |
| 샵 배너 | 800~4000px, 100MB 이하, JPG/PNG |
| 링크 | SNS 최대 10개 |
| 공개 여부 | 비공개 시 URL 접속 불가 |

- 이름·컨셉·대표 이미지 고민 → '콘텐츠샵 작명소 GPT' 활용.

### 상품 디자인 순서
1. 미리캔버스 에디터 진입 (워크스페이스에서 상품 선택)
2. 인쇄 제작 가이드(규격) 적용
3. 상품 디자인 유의사항 확인
4. 에디터에서 디자인 (내 요소·업로드 이미지 활용)
5. 상품 세부 옵션 선택
6. 해상도·오탈자 확인 (우측 패널 경고 확인)

### 상품 거부/제재 사유
1. 구매자가 텍스트·이미지를 **수정해야 구매 가능한** 디자인 (템플릿 성격 X, 완성형이어야 함)
2. 기존 템플릿/상품과 **매우 유사하거나 동일** (타인 템플릿 그대로·변형 사용, 이미 제출된 상품 복제)
3. 품질 기준 미달
4. 법적 문제·사회적 논란 (혐오·분쟁 유발, 저작권·초상권 침해, 타사 로고 등)
5. 메타데이터(썸네일, 상품명, 작가의 말) 부적절: 선정적·폭력적·혐오, 타인 권리 침해, 디자인과 무관한 설명, 웹툰 등 타 브랜드명 포함
6. 인쇄 문제: 칼선(보라색 선) 부적절, 저화질·복잡한 이미지/폰트, 안전선 밖 배치, 최소 폰트 크기 미준수
